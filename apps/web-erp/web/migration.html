Moving from the old system—

Sample data — this is not your shop.

Can we switch over

Eight checks. Every one of them is worked out from what is actually true — none of them is a box somebody ticks — and each says underneath where its answer came from.

Go back to the old system

One button. It needs nobody's approval and it works at any time, including in the middle of the switch-over. Nothing about the migration record is undone.

The figures

Every figure appears twice — what the old system says and what came across — with how each side was worked out. Both must agree exactly, and somebody who did not run the load must sign each one.

Sign a figure

Problems in the old data

Everything wrong with the old system's data, worst first, with the ones nobody has decided about at the top. Nothing here is ever deleted — a decided one stays on the list as the record that somebody looked at it.

Decide about one

Running both

Both systems ringing the same sales. Where they disagree, one of them is wrong about your shop, and somebody has to put their name to which. A bad day resets the count — the clean days only count from after the problem was fixed.

The old system

Everything the old shop keeps its records in, and anything about it nobody can answer. What is missing here is the point — a migration that starts with gaps migrates whatever somebody happened to remember.

Switching the old system off

Switching the old system off is not the same act as deleting the old data, and this screen never does the second one.
