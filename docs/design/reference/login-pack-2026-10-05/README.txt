SRE HYPER MARKET — LOGIN DESIGN PACK
5 October 2026

OPEN FIRST
Open SRE-Hypermarket-Login.html in a current desktop browser. No installation,
server, internet connection or build command is required. All icons are bundled.

TRY THE DESIGN
Use English / தமிழ், show or hide a sample password, open Help, and expand
“Explore states” to inspect the seven sample connection/account conditions.
Use made-up details only. Sign in demonstrates validation and then clears the
password. It never authenticates, creates an account or opens a real workspace.

WHAT IS INCLUDED
SRE-Hypermarket-Login.html — self-contained interactive design
source/login-markup.html — product markup for adaptation
source/login.css — scoped styles and responsive layout
source/login.js — bilingual copy and prototype interactions
design-tokens.json — colors, dimensions and state list
CLAUDE-HANDOVER.txt — implementation brief and acceptance checks
verification.json — checks performed and limitations
LUCIDE-LICENSE.txt — bundled icon library license

The source files are for integration, not a second runnable application.
The standalone HTML contains its own styles, behavior and Lucide icons.

DESIGN DIRECTION
Pale sage canvas, white login panel, forest-green text and emerald actions,
with a restrained segmented stripe. Desktop includes a store-workflow brand
panel; mobile prioritises the sign-in form. No marketing dashboard or invented
sales figures are displayed.

IMPLEMENTATION STATUS
This is a design handover. The repository and deployed application were not
changed. Connection status, store name, account eligibility and authentication
responses are samples. They must be replaced with real application state.
It is not evidence that offline authentication or deployment is complete.

Tamil text is supplied as draft interface copy; have a native-speaking staff
member review terminology and the actual installed font before release.
