## What the columns mean

| Column | A requirement has it when |
|---|---|
| Unit | a test under `tests/unit` cites it (an engine in isolation) |
| Integration (in-process) | a test under `tests/integration`, `tests/migration`, `tests/security` or `tests/contract` cites it (the real API or box assembly, in one process) |
| Real PostgreSQL | such a test needs `DATABASE_URL` — it runs on a real database in the required CI job |
| Browser (stub cloud) | a test under `tests/e2e` cites it — real Chromium drives the real screen against a stub or in-process cloud |
| Browser (connected) | that browser test also needs `DATABASE_URL` — the screen, the box and the real cloud on PostgreSQL in one run |
| Device | a PASS session in the SP-10 register on real hardware covers it |
| Staff UAT | a PASS session in the SP-10 register covers it |
| Label holds | the item's maturity label is allowed by the kinds it has (the rule in TEST-SCOPE §4) |
