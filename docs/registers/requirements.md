# Requirements register

Governance-level status of requirements: which are specified, approved, built and
verified. This is the **control** view; two companion files hold the detail:

- `docs/requirements/index.md` — the **catalogue** (every module, extension,
  workflow, gate, agent and control).
- `docs/traceability.md` — the **build trace** (design → code → tests → release,
  one row per requirement).

Stable IDs follow the roadmap (`M##-FR-##`, `D##-FR-##`, etc.).

> **Pending roadmap.** The full requirement set is expanded in Stage 2 from
> `docs/roadmap/roadmap-v2.0.docx`. Until that document is present, this register
> tracks only what the index has captured from Annexure H, at module granularity.

**In build** · **Verified** · **Deferred** (needs a `CH-##` row).
