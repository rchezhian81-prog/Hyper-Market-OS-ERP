# WF-03 — Purchase planning: scenario list

**Roadmap §26:** "Demand/min-max/budget → requisition → RFQ → comparison → approval → PO → acknowledgement/amendment" (M06, M09, A02).
**§26 WORKFLOW RULE:** "Each workflow requires separate happy-path, alternate, cancellation, permission-denied,
offline, timeout, duplicate, recovery and audit scenarios … A workflow is incomplete until its financial and stock
effects reconcile."

Each row names the automated test that proves the scenario (file › the test's own title), or says **MISSING** and why.
