# WF-07 — Stock transfer: scenario list

**Roadmap §26:** "Request → approve → pick/dispatch → in transit → receive/discrepancy → ledger" (M09, M08, M23).
**§31:** "Receiving/count/transfer: queue-capable."
**§26 WORKFLOW RULE:** happy-path, alternate, cancellation, permission-denied, offline, timeout, duplicate, recovery and
audit scenarios; the workflow is incomplete until its financial and stock effects reconcile.

Each row names the automated test that proves the scenario (file › the test's own title), or says **MISSING** and why.
`tests/guardrails/every-workflow-scenario-points-at-a-real-test.test.ts` checks that every named test exists.

are built and proved.
