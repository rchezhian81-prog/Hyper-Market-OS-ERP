# `docs/sop/`

Standard operating procedures written for staff who are not computer users: one printable page each, in English and
Tamil. Every sheet below exists in both languages, with the same numbered steps
(`tests/guardrails/the-owner-guide-and-sheets-hold-together.test.ts`).

| Id | Sheet | English | Tamil | Source |
|---|---|---|---|---|
| SOP-01 | The PC is down or the new till has stopped: old till only | `sop-01-pc-down.en.md` | `sop-01-pc-down.ta.md` | OB-255 |
| SOP-02 | Mirror keying for the pilot department | `sop-02-mirror-keying.en.md` | `sop-02-mirror-keying.ta.md` | OB-248, OB-252 |
| SOP-03 | The owner's evening check (parallel-run day) | `sop-03-owner-evening-check.en.md` | `sop-03-owner-evening-check.ta.md` | OB-254, MG-10 |
| SOP-04 | When a cashier forgets their PIN | `sop-04-forgotten-pin.en.md` | `sop-04-forgotten-pin.ta.md` | hard rule 4, ADR-0020 |

**Status, 20 Oct 2026:** written, not yet used in the store. SOP-02 step 5 (payment and cash-up on the new till) is a
marked placeholder waiting for lane 1; SOP-03 cannot be used on the store PC until the parallel-run terms can be written
there (owner guide, gap W-3). The Tamil has not yet been read by a Tamil-speaking member of staff: have it read for
plain wording before printing.
