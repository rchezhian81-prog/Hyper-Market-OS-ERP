# தாள் 4 — காசாளர் தன் PIN-ஐ மறந்துவிட்டால்
> **Not yet checked by a Tamil reader — check before the pilot grows beyond the first department (OB-261).**

**தாள் எண்:** SOP-04 · **விதிகள்:** கடுமையான விதி 4 (பகிர்ந்த உள்நுழைவு கூடாது), ADR-0020 (கல்லா PIN) · **மொழி:** தமிழ்
(ஆங்கிலம்: `sop-04-forgotten-pin.en.md`)
**யாருக்கு:** காசாளருக்கு (படிகள் 1–3), உரிமையாளருக்கு (படிகள் 4–7).

**காசாளர்:**

1. தொடர்ந்து ஊகித்து உள்ளிடாதீர்கள். **ஐந்து முறை தவறான PIN போட்டால் உங்கள் பணியாளர் குறியீடு பதினைந்து நிமிடங்கள்
   பூட்டப்படும்**; இருபது முறை உள்நுழைவு தோல்வியடைந்தால் முழுக் கல்லாவின் உள்நுழைவும் பதினைந்து நிமிடங்கள்
   பூட்டப்படும்.
2. **வேறொருவரின் பணியாளர் குறியீட்டையோ PIN-ஐயோ ஒருபோதும் பயன்படுத்தாதீர்கள்**; உங்களுக்காக வேறு யாரையும் உள்நுழைய
   விடாதீர்கள்.
3. உரிமையாளரிடம் சொல்லுங்கள். புதிய PIN கிடைக்கும் வரை, எப்போதும் போல பழைய கல்லாவில் பில் போடுங்கள், புதிய கல்லாவில்
   பதிவு செய்யாதீர்கள்: தாள் 1 அட்டவணையில் நேரத்தை எழுதி, நடுக் கட்டத்தில் "PIN இல்லை" என்று எழுதுங்கள்.

**உரிமையாளர்:**

4. **உங்கள் சொந்த** Windows கணக்கில் (காசாளரின் `Till` கணக்கில் ஒருபோதும் இல்லை), அமைப்பின் கோப்புறையில் (`C:\SRE`,
   அல்லது புதுப்பித்த பிறகு புதிய வெளியீட்டுக் கோப்புறையில்) PowerShell-ஐத் திறந்து, காசாளரின் பணியாளர் குறியீட்டையும்
   உங்கள் பெயரையும் போட்டு இதை உள்ளிடுங்கள்:
   ```
   pnpm run till:pin -- --user <their-staff-id> --by "Your Name"
   ```
5. புதிய ஆறு இலக்க PIN **ஒரே ஒரு முறை** தோன்றும். **இந்தச் சாளரத்தில் ரகசியம் உள்ளது: அதைப் புகைப்படம் எடுக்காதீர்கள்.**
   திரையைக் காசாளர் பக்கம் திருப்பி, அவர் படிக்கும்போது நீங்கள் வேறு பக்கம் பாருங்கள். அவருக்காக எழுதிக்
   கொடுக்காதீர்கள், தொலைபேசியிலோ செய்தியிலோ அனுப்பாதீர்கள். சாளரத்தை மூடுங்கள். பழைய PIN உடனே வேலை செய்வது
   நின்றுவிடும் — கல்லாவிலும், மேலாளருக்கு அலுவலகத் திரைகளிலும்.
6. PIN வேறொருவருக்குத் தெரிந்திருக்கலாம் என்றாலோ, அந்த நபர் வேலையை விட்டுச் செல்கிறார் என்றாலோ, அதற்குப் பதிலாக அதே
   வரியின் கடைசியில் `--revoke` சேர்த்து உள்ளிடுங்கள். அவருடைய அடுத்த உள்நுழைவு மறுக்கப்படும்.
7. பதிவேட்டில் (workbook) எழுதுங்கள்: தேதி, பணியாளர் குறியீடு, "புதிய PIN கொடுக்கப்பட்டது" அல்லது "PIN ரத்து
   செய்யப்பட்டது", உங்கள் கையொப்பம். **PIN-ஐ ஒருபோதும் எழுதாதீர்கள்.**
