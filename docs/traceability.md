# Traceability

One row per **individual requirement** (not per module). Every requirement in the
roadmap must appear here and be traceable from design through to a passing test
and the release it shipped in. This table is part of the Definition of Done in
`CLAUDE.md` and is updated as work is completed.

- **Requirement ID** — the stable ID from the roadmap (e.g. `M03-FR-01`, `D03-FR-02`).
- **Stage** — the execution stage (0–19) in which it is delivered.
- **Design** — link to the design / requirement document that specifies it.
- **Code** — link to the implementing code (app, service, edge or package).
- **Tests** — link to the automated tests that prove it.
- **Release** — the release it shipped in (R0–R8).
- **Status** — `Not started` · `In design` · `In build` · `In test` · `Done` · `Deferred`.
